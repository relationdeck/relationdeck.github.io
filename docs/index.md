# 卡牌資源

這裡整理 RelationDeck 關係盒子的使用方式、每副牌的介紹，以及常見問題。

## 從這裡開始

- [使用指南](./how-to-use.md)：抽卡、筆記、對話者、紀錄與每日提醒怎麼用。
- [常見問題](./faq.md)：資料存在哪裡、需不需要網路、怎麼記錄多人的回答。

## 八副牌

App 收錄 8 副牌，每副 15 張，共 120 張卡。每張卡依深度分為「輕鬆」「深入」「深度」三個層次。

| 牌組 | 適合對象 | 一句話 |
|---|---|---|
| [個人反思](./decks/reflection.md) | 自己 | 一個人靜下來，用問題問自己。 |
| [陌生破冰](./decks/stranger.md) | 剛認識的人 | 初次見面，不再只是寒暄。 |
| [朋友聚會](./decks/friend.md) | 朋友 | 一道好問題，勝過三小時的閒聊。 |
| [曖昧約會](./decks/dating.md) | 約會對象 | 讓一張卡替你開口，慢慢靠近彼此。 |
| [伴侶深談](./decks/partner.md) | 伴侶 | 不只聊日常，而是聊心裡。 |
| [家庭時光](./decks/family.md) | 家人 | 少一點客套，多一點傾聽。 |
| [職場交流](./decks/colleague.md) | 同事 | 不只是合作，而是理解彼此。 |
| [下屬對話](./decks/subordinate.md) | 部屬（1-on-1） | 不只是管理，而是建立信任。 |
