# 卡牌資源

這裡整理 RelationDeck 關係盒子的使用方式、每副牌的介紹，以及常見問題。

## 從這裡開始

- [使用指南](./how-to-use.md)：抽卡、收藏、筆記、對話者、回顧與每日提醒怎麼用。
- [常見問題](./faq.md)：資料存在哪裡、需不需要網路、怎麼記錄多人的回答。

## 十二副牌

App 收錄 12 副牌，每副 30 張，共 360 張卡。每張卡依深度分為「輕鬆」「深入」「深度」三個層次；陌生破冰只有「輕鬆」與「深入」，因為深度的題目，留給已經認識的人。

| 牌組 | 適合對象 | 一句話 |
|---|---|---|
| [個人反思](./decks/reflection.md) | 自己 | 一個人靜下來，用問題問自己。 |
| [陌生破冰](./decks/stranger.md) | 剛認識的人 | 初次見面，不再只是寒暄。 |
| [朋友聚會](./decks/friend.md) | 朋友 | 一道好問題，勝過三小時的閒聊。 |
| [曖昧約會](./decks/dating.md) | 約會對象 | 不知道說什麼才好？讓一張卡替你開口。 |
| [伴侶深談](./decks/partner.md) | 伴侶 | 不只聊日常，而是聊心裡。 |
| [共同生活](./decks/household.md) | 同居或婚後的伴侶 | 相愛容易，一起過日子要靠談。 |
| [子女對談](./decks/family.md) | 子女問爸媽 | 少一點客套，多一點傾聽。 |
| [父母對談](./decks/parenting.md) | 爸媽問孩子 | 不只問「今天乖不乖」。 |
| [手足對談](./decks/sibling.md) | 兄弟姊妹 | 同一個家長大，卻有不同的記憶。 |
| [職場交流](./decks/colleague.md) | 同事 | 不只是合作，而是理解彼此。 |
| [向上對談](./decks/upward.md) | 主管或導師 | 不只是報告，而是了解帶領你的人。 |
| [下屬對話](./decks/subordinate.md) | 部屬（1-on-1） | 不只是管理，而是建立信任。 |
